#  Flight Price Data Analysis

##  Project Overview
This is an end-to-end Data Analytics project that analyzes flight pricing data to identify key patterns, popular routes, airline performance, and the impact of duration and stops on ticket prices. 

The project follows a complete analytics workflow: **Excel → Python → SQL → Power BI**.

##  Tools & Technologies Used
* **Excel:** Initial data review and basic cleaning.
* **Python (Pandas, Matplotlib, Seaborn):** Data manipulation and Exploratory Data Analysis (EDA).
* **MySQL:** Business analysis, querying metrics, and validating data logic.
* **Power BI:** Building interactive dashboards for data visualization.

##  Dashboards Created
1. **Flight Overview Report:** Overall market view showing total flights, average prices, and airline counts by source and destination.
2. **Price & Route Analysis:** Detailed breakdown of the most popular, cheapest, and most expensive routes.
3. **Time, Duration & Stops Analysis:** Insights into how departure hours, journey months, and number of stops impact the final ticket price.

##  Key Business Insights
* **Most Expensive Airline:** Jet Airways Business (Avg Price: ₹58,358)
* **Most Affordable Airline:** Trujet (Avg Price: ₹4,140)
* **Most Popular Route:** DEL → BOM → COK (2,376 flights)
* **Most Expensive Route:** BOM → DED → DEL → HYD (Avg Price: ₹24,115)
* **Timing Impact:** Early morning flights (around 3:00 AM) tend to have the highest average prices.
* **Monthly Trend:** March recorded the highest average ticket prices, whereas April had the lowest.
